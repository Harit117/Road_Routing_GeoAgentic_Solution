# Historical rainfall scenarios

The scenarios are derived from the historical Velachery hourly rainfall record.
P75, P90, P95, and P99 are calculated from the distribution of trailing
rolling 24-hour rainfall totals. Local maxima are declustered with at least
seven days between selected events. Each scenario preserves a historical
48-hour hourly rainfall sequence around its selected peak.

These sequences are temporal rainfall forcing inputs for the downstream
flood-risk/bucket model. They are not physical flood-depth predictions and do
not claim to predict exact flood depth or flood onset. OpenCity historical
flood data provides spatial susceptibility, while this rainfall dataset
provides temporal rainfall forcing. Applying the same representative Velachery
rainfall forcing to nearby linked road/flood points is a prototype assumption.
